## Visual authority

README.md and assets/systems-lab.svg are the production source. The design boards
render that same Markdown rather than maintaining separate marketing copy.
GitHub controls the surrounding page, body typography, links and focus behavior.
The original, locally stored SVG supplies the science-fiction identity without
external fonts, scripts, third-party artwork, or third-party hero rendering.

Banner palette: deep blue #0b1220, cyan #75e8e1, primary text #eff6ff,
secondary text #b9c8dc, annotation #a9b8cf. Thin geometric lines are decoration.
Use system sans for the name and system monospace for labels. Cyan framing and
orbital geometry adapt the reference principles; no reference assets are copied.
The dark banner intentionally works on both GitHub themes. Main content inherits
the viewer's theme. Avoid wide content tables and image-only project descriptions.

## Motion and review

Production is static: there is no live process or state that warrants animation.
No blinking terminal, typing loop, fake telemetry or fake availability indicator.
The review player's scene transitions use the kit's 480ms ease-standard token;
its progress controls express navigation. Reduced motion disables transitions
and starts playback paused. These are review controls, not promised GitHub features.
